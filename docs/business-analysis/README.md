## Locked context

- **Brand**: DealStoker

## How to use

1. `03`의 확정 결정을 전제로 `01` 범위를 읽는다.  
2. `02`의 Phase 1 → 1.5(Associates) → 2(PA-API Job) 순서를 따른다.  
3. 재신청 실무는 [Associates checklist](../associates/reapplication-checklist.md)를 따른다.  
4. 남은 ADR(SSR, Draft 기본값 등)만 추가 합의 후 스캐폴딩한다.
