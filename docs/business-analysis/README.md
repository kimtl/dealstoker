# DealStoker Business Analysis Pack

이 폴더는 Affiliate Marketing 웹사이트(DealStoker)의 Business Analyst 산출물이다.

## Documents

| Doc | Description |
|-----|-------------|
| [01-requirements-analysis.md](./01-requirements-analysis.md) | 비즈니스 목표, 이해관계자, 기능/비기능 요구사항, 도메인, 리스크, MVP 범위 |
| [02-implementation-plan.md](./02-implementation-plan.md) | 아키텍처, 모듈, API/Job/SEO 구현 요구, 페이즈 계획, 수용 기준, 다음 액션 |

## How to use

1. `01`로 범위·우선순위·오픈 이슈를 합의한다.  
2. `02`의 ADR/Phase 0 전에 마켓·SSR·자동발행 정책을 확정한다.  
3. 합의된 MVP 기준으로 엔지니어링 백로그를 분해한다.
