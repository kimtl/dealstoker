# DealStoker

US-focused affiliate marketing website for [dealstoker.com](https://dealstoker.com) — category-based Amazon.com product curation, SEO-driven traffic, and (post Associates approval) automated product ingestion.

**Stack target:** Spring Boot + React  
**Market:** United States (Amazon.com, en-US, USD)
